
### Goal
- >=70% Automation
- 客户满意度
- 延迟：p50 < 1s, p95 < 2.5s （回复延迟直接影响用户的满意度）
### Scope
- 退货，换货，订单状态，以及运输状态
### Rules
- 退货窗口只能小于30天，不能损坏
- 退货政策（小于50刀自动处理，大于50需要管理者）
- 换货政策：商品状态，允许换货的类别
- 人类兜底处理：用户想要一个人工客服，用户情绪检测
### Backend/DB
- Peak RPS(Requests Per Second) & Seasonality （请求数据是否有季节性） 
- 数据存储：关系数据库 or 向量数据库
